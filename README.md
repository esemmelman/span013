# Spanish Question Quiz

A mobile-friendly quiz with 14 Spanish questions, challenging English translation choices, and large bold text. Shows one question at a time with immediate scoring. Correct answers advance after two seconds. Incorrect answers unlock clickable Spanish-to-English word translations and a large Next button. The bottom restart button clears the score and shuffles both questions and choices.

Open `index.html` in a browser. No build step or account is needed. Answers are not sent to a server.

The site is published with GitHub Pages from the main branch.
